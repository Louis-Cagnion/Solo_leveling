# Solo_leveling

Ce projet est une interface personnelle de progression en programmation. Elle s'inspire des systèmes de niveaux, de rangs et de titres de *Solo Leveling* et de l'école 42. Elle s'appuie sur les données de suivi de `/professor`, sans reprendre leur collecte, et distingue ce qui est observé, ce qui est estimé et ce qui reste insuffisant pour conclure.

## État actuel

Le projet en est au cadrage : aucune maquette ni ligne de code n'existe encore. Les décisions préalables listées au §12 de la spécification doivent être validées d'abord.

- `docs/specification.md` : le cahier des charges.
- `docs/plan.md` : les phases, le cadrage et l'arbre des tâches en cours.
